# 群名片定时提醒

适用于 AstrBot 的 QQ OneBot v11（`aiocqhttp`）插件。每天按多个北京时间检查指定群的**群名片**（OneBot 成员字段 `card`），根据是否包含指定字符筛选成员，并在群内用真实 @ 消息段提醒。可按 QQ 号指定不参与 @ 的成员。

## 安装与配置

从 [v0.1.0 Release](https://github.com/ma114514/astrbot_plugin_group_card_reminder/releases/tag/v0.1.0) 下载 `astrbot_plugin_group_card_reminder_v0.1.0.zip`，在 AstrBot WebUI 的插件页上传，然后打开此插件的设置：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `group_ids` | 空列表 | 点击“添加更多”，一项填写一个 QQ 群号；也接受 `aiocqhttp:GroupMessage:群号` |
| `excluded_qq_ids` | 空列表 | 不加入 @ 名单的 QQ 号，一项填一个；仅按此名单排除 |
| `keywords` | 空列表 | 点击“添加更多”，一项填写一个普通文本片段；不使用正则 |
| `match_mode` | 缺少关键词时提醒 | 正向：不含任何一项则提醒；反向：包含任意一项则提醒 |
| `check_times` | `09:00` | 点击“添加更多”，一项填写一个北京时间 `HH:MM` |
| `single_mention_limit` | `0` | 每群在一个检查时间点最多 @ 多少人；`0` 表示不限额 |
| `daily_mention_limit` | `0` | 每群每天累计最多 @ 多少人；`0` 表示不限额 |
| `reminder_text` | `请按群规定修改群名片。` | 发在 @名单前的文字 |

例如，添加 `部门`、`学生` 两项后，选“缺少关键词时提醒”，群名片两者都不含的成员会被提醒；选“包含关键词时提醒”，群名片含有任意一项的成员会被提醒。匹配区分大小写。空名片在前一种模式下会被提醒，在后一种模式下不会。可添加 `09:00`、`18:30` 等多个时间点，保存配置后重载插件；已经过去的时间点从次日开始运行。

发送账号必须在目标群内，且连接的 OneBot 协议端需要支持 `get_login_info`、`get_group_member_list` 和 `send_group_msg`。若多个 QQ 账号同时在一个目标群中，插件按账号 QQ 号顺序选择首个可获取有效成员列表的账号，同一群只发送一轮提醒。发送账号如需免于被 @，也请填入 `excluded_qq_ids`。

AstrBot 管理员可在目标群发送 `/群名片检查`，预览符合提醒条件的前 30 位成员及当前额度；预览不会发送 @ 或占用额度。

## 发送和故障处理

- 每条提醒最多 @20 人；人数超过时分批发送。没有不合格成员时不发消息。
- 单次限额约束一个群在一个检查时间点的 @人数，跨消息分批时仍合计计算；每日总限额由同一群的所有时间点共用。两项同时设置时取较小的可用额度；重复 @同一人也计一次。每日总额度在北京时间次日重新计算。
- 需要筛选时，优先选择该群中**从未被本插件成功 @过**的成员；同为首次提醒的成员按 QQ 号排序。若仍有名额，再对已提醒成员随机抽取，历史成功 @次数每增加一次，抽取权重减半（例如 1 次为 `1/2`，2 次为 `1/4`）。每次抽取后移除该成员，同一时间点不会重复 @。个人历史跨天保存，重载插件后继续生效；每日总额度仍在北京时间次日重置。
- 查询失败或成员数据缺字段时不发送提醒，避免误判。
- 排除名单中的 QQ 号不会出现在手动预览或定时 @名单中，也不会占用每日 @额度。
- 每群每个时间点每天只尝试发送一次。发送前会将该时间点和本次 @人数一并写入 AstrBot 插件数据目录；发送接口确认成功后，才增加该批成员的个人历史次数。若发送中途失败，同一时间点当天不会自动重发，预留的额度也不会退回。失败原因会写入 AstrBot 日志。
- 如果前一时间点的扫描执行过久，后续已到的时间点会在它结束后依次执行。
- 群列表、关键词列表或时间列表为空时不会定时扫描；某个时间格式错误时不会发送提醒。修改配置后请重载插件。

仅使用 Python 标准库，无额外依赖。
